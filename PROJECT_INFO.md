## Описание

Мессенджер для Android с текстовыми сообщениями, голосовыми звонками и обменом файлами.

---

## Технические детали

| Параметр | Значение |
|----------|----------|
| Платформа | Android 5.0+ |
| Язык | Java + HTML/CSS/JS |
| GUI | WebView |
| Сборка | Gradle |
| Размер APK | ~100 KB |

---

## Функции

- Текстовый чат
- Голосовые звонки (имитация)
- Обмен файлами (имитация)
- Список пользователей
- Настройки
- История чата
