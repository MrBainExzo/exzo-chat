# 📜 Кодекс поведения

## Наши стандарты

### Позитивное поведение

- Использование приветливого языка
- Уважение к разным точкам зрения
- Конструктивная критика
- Фокус на том, что лучше для сообщества

### Негативное поведение

- Trolling и оскорбления
- Harassment
- Публикация чужой информации без разрешения
- Другое неприемлемое поведение
