## Как получить APK

### Вариант 1: Android Studio (рекомендуется)

1. Скачайте и установите Android Studio
2. Откройте проект `exzo_chat_android`
3. Нажмите Run (▶)
4. Готово!

### Вариант 2: GitHub Actions (бесплатно)

1. Загрузите проект на GitHub
2. Перейдите в Actions
3. Запустите workflow "Build APK"
4. Скачайте APK из Artifacts

### Вариант 3: Командная строка

```bash
chmod +x gradlew
./gradlew assembleDebug
```

## Как установить

### Через USB

```bash
adb install app-debug.apk
```

### Вручную

1. Скопируйте APK на устройство
2. Откройте файловый менеджер
3. Нажмите на APK файл
4. Нажмите "Установить"

## Как использовать

### Первый запуск

1. Откройте приложение
2. Введите никнейм
3. Введите IP сервера
4. Нажмите "Подключиться"

### Отправка сообщений

1. Введите текст в поле ввода
2. Нажмите "➤" или Enter

### Голосовые звонки

1. Выберите пользователя из списка
2. Нажмите "📞 Позвонить"
3. Дождитесь ответа
