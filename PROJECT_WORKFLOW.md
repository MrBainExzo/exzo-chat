## Git Workflow

### Ветки

- `main` — стабильная версия
- `develop` — разработка
- `feature/*` — новые функции
- `bugfix/*` — исправление ошибок
- `release/*` — подготовка к релизу

### Коммиты

- Формат: `тип: описание`
- Типы: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

### Pull Requests

- Описание изменений
- Код ревью
- Тестирование
- Merge
