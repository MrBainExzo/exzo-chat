# 🔧 Устранение проблем

## Проблемы со сборкой

### Android Studio не видит проект

**Решение:**
1. File → Sync Project with Gradle Files
2. Дождитесь завершения
3. Повторите попытку

### Gradle sync failed

**Решение:**
1. File → Invalidate Caches / Restart
2. Повторите синхронизацию
3. Если не помогло, удалите папку `.gradle`

### SDK not found

**Решение:**
1. File → Project Structure → SDK Location
2. Укажите путь к Android SDK
3. Или установите SDK через SDK Manager

### Java not found

**Решение:**
1. Установите JDK 11+
2. File → Project Structure → SDK Location → JDK
3. Укажите путь к JDK

### Build failed

**Решение:**
1. Проверьте логи ошибок (View → Tool Windows → Build)
2. Исправьте ошибки
3. Повторите сборку

## Проблемы с установкой

### "Установка заблокирована"

**Решение:**
1. Настройки → Безопасность
2. Включите "Неизвестные источники"
3. Попробуйте установить снова

### "Приложение не установлено"

**Решение:**
1. Удалите предыдущую версию
2. Очистите место на устройстве
3. Перезагрузите устройство

### "Ошибка парсинга пакета"

**Решение:**
1. Скачайте APK заново
2. Проверьте версию Android (нужна 5.0+)
3. Проверьте архитектуру устройства

---

## Проблемы с приложением

### Приложение не запускается

**Решение:**
1. Очистите кэш приложения
2. Переустановите приложение
3. Проверьте разрешения

### Не подключается к серверу

**Решение:**
1. Проверьте IP адрес сервера
2. Проверьте интернет-соединение
3. Проверьте файрвол

### Нет звука

**Решение:**
1. Проверьте разрешения на микрофон
2. Проверьте громкость устройства
3. Попробуйте наушники

### Не отправляются сообщения

**Решение:**
1. Проверьте подключение к серверу
2. Проверьте интернет-соединение
3. Переподключитесь

## Проблемы с GitHub Actions

### Workflow не запускается

**Решение:**
1. Проверьте, что workflow файл в правильной папке
2. Проверьте синтаксис YAML
3. Проверьте настройки репозитория

### Build failed в Actions

**Решение:**
1. Проверьте логи ошибок
2. Убедитесь, что все файлы на месте
3. Проверьте зависимости

### Artifacts не скачиваются

**Решение:**
1. Проверьте, что сборка завершена
2. Попробуйте другой браузер
3. Проверьте настройки репозитория
