# 🏗️ Архитектура

## Обзор

Exzo Chat Android построен на базе WebView и использует HTML/CSS/JS для интерфейса.

---

## Компоненты

### 1. MainActivity (Java)

Основная активность приложения. Отвечает за:

- Запуск WebView
- Настройки WebView
- Обработка событий

### 2. index.html (HTML/CSS/JS)

Пользовательский интерфейс. Содержит:

- HTML разметку
- CSS стили
- JavaScript логику

### 3. AndroidManifest.xml

Манифест приложения. Содержит:

- Разрешения
- Активности
- Настройки

## Потоки данных

### 1. Запуск приложения

```
User → MainActivity → WebView → index.html → Display
```

### 2. Отправка сообщения

```
User Input → JavaScript → Display
```

### 3. Подключение к серверу

```
User Input → JavaScript → WebSocket (planned) → Server
```
