# 🚨 Реагирование на инциденты

## Определения

### Severity levels

| Level | Описание |
|-------|----------|
| P0 | Критично — приложение недоступно |
| P1 | Высокий — критическая функция не работает |
| P2 | Средний — важная функция не работает |
| P3 | Низкий — незначительная проблема |

---

## Процесс

### 1. Обнаружение

- Алерты мониторинга
- Сообщения пользователей

### 2. Оценка

- Определить severity
- Оценить impact

### 3. Реакция

- Назначить ответственного
- Исправить проблему

### 4. Восстановление

- Проверить исправление
- Развернуть исправление

### 5. Анализ

- Провести post-mortem
- Определить root cause
