# 📤 Распространение проекта

## Способы распространения

### 1. Прямая передача

- Скачайте `exzo_chat_android.zip`
- Передайте получателю
- Получатель распакует и соберет APK

### 2. GitHub

1. Создайте репозиторий на GitHub
2. Загрузите файлы проекта
3. Поделитесь ссылкой на репозиторий
4. Получатели клонируют репозиторий

### 3. Облачное хранилище

1. Загрузите `exzo_chat_android.zip` в облако
2. Получите публичную ссылку
3. Поделитесь ссылкой

## Инструкции для получателей

### Быстрый старт

1. Скачайте и распакуйте архив
2. Откройте проект в Android Studio
3. Нажмите Run (▶)
4. Установите APK на устройство
5. Запустите приложение

### Подробные инструкции

- [START_HERE.md](START_HERE.md) — начните здесь
- [QUICK_BUILD.md](QUICK_BUILD.md) — быстрая сборка
- [BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md) — инструкция по сборке
- [INSTALL_APK.md](INSTALL_APK.md) — инструкция по установке

## Требования к получателям

### Для сборки

- Android Studio 2022.3+
- Java JDK 11+
- Android SDK API 21+
- 4 GB RAM
- 2 GB места

### Для установки

- Android 5.0+
- 10 MB места
