# 🤝 Совместное использование

## Как поделиться проектом

### Способ 1: ZIP архив

1. Скачайте `exzo_chat_android.zip`
2. Отправьте получателю
3. Получатель распакует и соберет APK

### Способ 2: GitHub

1. Создайте репозиторий
2. Загрузите файлы
3. Поделитесь ссылкой

### Способ 3: Облачное хранилище

1. Загрузите в облако
2. Получите ссылку
3. Поделитесь ссылкой

## Инструкции для получателей

### Быстрый старт

1. Скачайте архив
2. Распакуйте
3. Откройте в Android Studio
4. Нажмите Run (▶)
5. Установите APK

## Требования

### Для сборки

- Android Studio 2022.3+
- Java JDK 11+
- Android SDK API 21+

### Для установки

- Android 5.0+
- 10 MB места
