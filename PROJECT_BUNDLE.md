# 📦 Комплект проекта

## В комплект входит

### Исходный код

- `MainActivity.java` — Java код
- `index.html` — HTML/CSS/JS интерфейс
- `AndroidManifest.xml` — манифест
- `build.gradle` — конфигурация

### Документация

- 30+ файлов документации
- Подробные инструкции
- Примеры использования
- Устранение проблем

### Инструменты сборки

- `build.yml` — GitHub Actions workflow
- `gradle-wrapper.properties` — настройки Gradle
- `gradlew` — скрипт запуска Gradle

## Сборка

### Варианты

1. **Android Studio** — самый простой
2. **GitHub Actions** — бесплатно
3. **Командная строка** — для опытных

### Время сборки

| Способ | Время |

| Android Studio (первый раз) | 5-10 мин |

| GitHub Actions | 5-10 мин |

## Использование

### Первый запуск

1. Откройте приложение
2. Введите никнейм
3. Введите IP сервера
4. Нажмите "Подключиться"

### Отправка сообщений

1. Введите текст
2. Нажмите "➤"

### Звонки

1. Выберите пользователя
2. Нажмите "📞 Позвонить"
3. Дождитесь ответа
