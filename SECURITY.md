# 🔒 Безопасность

## Политика безопасности

### Сбор данных

- Нет сбора персональных данных
- Нет аналитики
- Нет рекламы

### Хранение данных

- Локальное хранение на устройстве
- Нет облачного хранения
- Нет передачи данных третьим лицам

### Разрешения

| Разрешение | Назначение |
|------------|------------|
| INTERNET | Подключение к серверу |
| RECORD_AUDIO | Голосовые звонки |
| READ/WRITE_EXTERNAL_STORAGE | Обмен файлами |

## Рекомендации

### Для пользователей

1. Не подключайтесь к незнакомым серверам
2. Используйте VPN в публичных сетях
3. Не передавайте личную информацию
4. Обновляйте приложение

### Для разработчиков

1. Валидируйте входные данные
2. Не храните секреты в коде
3. Проводите аудит кода

## Известные ограничения

- Нет end-to-end шифрования
- Нет аутентификации сервера
- Нет защиты от MITM
