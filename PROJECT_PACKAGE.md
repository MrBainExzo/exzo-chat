## Как использовать

### 1. Распакуйте архив

Распакуйте `exzo_chat_android.zip` в любую папку.

### 2. Соберите APK

**Android Studio:**
1. Откройте проект
2. Нажмите Run (▶)

**GitHub Actions:**
1. Загрузите на GitHub
2. Запустите workflow
3. Скачайте APK

### 3. Установите на устройство

1. Скопируйте APK на устройство
2. Откройте файловый менеджер
3. Установите APK

### 4. Запустите приложение

1. Откройте Exzo Chat
2. Введите никнейм
3. Подключитесь к серверу
4. Общайтесь!
