# 📱 Exzo Chat Android — Полная документация

## Обзор

Exzo Chat — это мессенджер для Android с текстовыми сообщениями, голосовыми звонками и обменом файлами.

---

## Быстрый старт

### 1. Скачайте проект

Скачайте `exzo_chat_android.zip` и распакуйте.

### 2. Соберите APK

**Android Studio:**
1. Откройте проект
2. Нажмите Run (▶)

**GitHub Actions:**
1. Загрузите на GitHub
2. Запустите workflow
3. Скачайте APK

### 3. Установите на устройство

1. Скопируйте APK на устройство
2. Откройте файловый менеджер
3. Установите APK

### 4. Запустите приложение

1. Откройте Exzo Chat
2. Введите никнейм
3. Подключитесь к серверу
4. Общайтесь!

## Сборка

### Android Studio

1. Откройте проект
2. Дождитесь синхронизации
3. Нажмите Run (▶)

### Командная строка

```bash
chmod +x gradlew
./gradlew assembleDebug
```

### GitHub Actions

1. Загрузите на GitHub
2. Actions → Build APK → Run workflow
3. Скачайте APK из Artifacts

## Использование

### Первый запуск

1. Откройте приложение
2. Введите никнейм
3. Введите IP сервера
4. Нажмите "Подключиться"

### Отправка сообщений

1. Введите текст
2. Нажмите "➤"

### Звонки

1. Выберите пользователя
2. Нажмите "📞 Позвонить"
3. Дождитесь ответа

## Устранение проблем

### Приложение не запускается

1. Очистите кэш
2. Переустановите приложение
3. Проверьте разрешения

### Не подключается к серверу

1. Проверьте IP адрес
2. Проверьте интернет
3. Проверьте файрвол

### Нет звука

1. Проверьте разрешения
2. Проверьте громкость
3. Попробуйте наушники
