## Описание

Мессенджер для Android с текстовыми сообщениями, голосовыми звонками и обменом файлами.

---

## Технический стек

| Компонент | Технология |
|-----------|------------|
| GUI | WebView + HTML/CSS/JS |
| Платформа | Android 5.0+ |
| Язык | Java |
| Сборка | Gradle |

---

## Функции

### Реализованные

- Текстовый чат
- Голосовые звонки (имитация)
- Обмен файлами (имитация)
- Список пользователей
- Настройки
- История чата

### Планируемые

- Реальное подключение к серверу
- Голосовые звонки
- Обмен файлами
- Эмодзи

## Сборка

### Android Studio

1. Откройте проект
2. Нажмите Run (▶)

### Командная строка

```bash
./gradlew assembleDebug
```

### GitHub Actions

1. Загрузите на GitHub
2. Запустите workflow
3. Скачайте APK

---

## Установка

### Через USB

```bash
adb install app-debug.apk
```

### Вручную

1. Скопируйте APK на устройство
2. Откройте файловый менеджер
3. Установите APK
