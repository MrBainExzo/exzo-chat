# 🤝 Как помочь

## Способы помощи

### 1. Сообщить об ошибке

1. Перейдите в GitHub Issues
2. Создайте новый Issue
3. Опишите проблему

### 2. Предложить улучшение

1. Перейдите в GitHub Issues
2. Создайте новый Issue
3. Опишите улучшение

### 3. Внести код

1. Fork проекта
2. Создайте ветку
3. Внесите изменения
4. Отправьте Pull Request

### 4. Улучшить документацию

1. Исправьте опечатки
2. Добавьте примеры
3. Переведите на другие языки

---

## Стандарты кода

### Java

- Следуйте Google Java Style Guide
- Добавляйте комментарии
- Пишите тесты

### HTML/CSS/JS

- Следуйте Airbnb JavaScript Style Guide
- Используйте semantic HTML
- Пишите чистый CSS

### Коммиты

- Формат: `тип: описание`
- Типы: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

### 1. Подготовка

```bash

git clone https://github.com/your-username/exzo-chat-android.git
cd exzo-chat-android

# Создайте ветку
git checkout -b feature/my-feature
```

### 2. Разработка

```bash
# Внесите изменения
# Протестируйте
```

### 3. Отправка

```bash
# Добавьте изменения
git add .

# Создайте коммит
git commit -m "feat: мое улучшение"

# Отправьте ветку
git push origin feature/my-feature
```

### 4. Pull Request

1. Перейдите на GitHub
2. Создайте Pull Request
3. Опишите изменения
4. Дождитесь ревью
