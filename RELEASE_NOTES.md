# 📋 Release Notes

## v1.0.0 (2026-08-24)

### 🎉 Initial Release

Первая версия Exzo Chat для Android!

### ✨ Новые функции

- **Текстовый чат** — обмен сообщениями
- **Голосовые звонки** — имитация звонков
- **Обмен файлами** — имитация обмена
- **Список пользователей** — отображение участников
- **Настройки** — управление профилем
- **История чата** — сохранение сообщений

### 🔧 Технические детали

- **GUI:** WebView + HTML/CSS/JS
- **Платформа:** Android 5.0+
- **Размер APK:** ~100 KB

### 📝 Примечания

- Демо версия
- Базовый функционал
- Для тестирования
