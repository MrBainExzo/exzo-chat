## Как получить APK

### Вариант 1: Android Studio

1. Откройте проект
2. Нажмите Run (▶)
3. Готово!

### Вариант 2: GitHub Actions

1. Загрузите на GitHub
2. Запустите workflow
3. Скачайте APK

### Вариант 3: Командная строка

```bash
./gradlew assembleDebug
```
