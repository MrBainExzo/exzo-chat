# 🔄 Обновление

## Общая информация

Этот документ описывает процесс обновления Exzo Chat Android.

---

## Обновление с v1.0.0

### Процесс

1. Скачайте новую версию
2. Удалите старую версию
3. Установите новую версию

### Миграция данных

- Настройки сохраняются
- История чата сохраняется

---

## Откат до предыдущей версии

### Процесс

1. Удалите текущую версию
2. Установите предыдущую версию

---

## Резервное копирование

### Что копировать

- Настройки
- История чата

### Как копировать

```bash
# Через ADB
adb pull /data/data/com.exzo.chat/files/ ./
```
