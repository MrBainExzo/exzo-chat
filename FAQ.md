# ❓ Частые вопросы

## Общие

### Что такое Exzo Chat?

Exzo Chat — это мессенджер для Android с текстовыми сообщениями, голосовыми звонками и обменом файлами.

### Сколько стоит приложение?

Бесплатно.

### Нужен ли интернет?

Да, для подключения к серверу.

---

## Сборка

### Как собрать APK?

**Самый простой способ:**
1. Установите Android Studio
2. Откройте проект
3. Нажмите Run (▶)

**Бесплатный способ:**
1. Загрузите на GitHub
2. Используйте GitHub Actions
3. Скачайте APK из Artifacts

### Сколько времени занимает сборка?

- Android Studio: 5-10 минут (первый раз), 1-2 минуты (повторно)
- GitHub Actions: 5-10 минут

### Какой размер APK?

~100 KB (очень маленький!)

---

## Установка

### Как установить APK?

1. Скопируйте APK на устройство
2. Откройте файловый менеджер
3. Нажмите на APK файл
4. Нажмите "Установить"

### Почему не устанавливается?

**Причины:**
- Не включена установка из неизвестных источников
- Недостаточно места
- Поврежденный APK файл

**Решения:**
1. Включите установку из неизвестных источников
2. Очистите место
3. Скачайте APK заново

---

## Использование

### Как подключиться к серверу?

1. Откройте приложение
2. Введите никнейм
3. Введите IP сервера
4. Нажмите "Подключиться"

### Как отправить сообщение?

1. Введите текст в поле ввода
2. Нажмите "➤" или Enter

### Как позвонить?

1. Выберите пользователя
2. Нажмите "📞 Позвонить"
3. Дождитесь ответа

## Проблемы

### Приложение не запускается

**Решение:**
1. Очистите кэш
2. Переустановите приложение
3. Проверьте разрешения

### Не подключается к серверу

**Решение:**
1. Проверьте IP адрес
2. Проверьте интернет
3. Проверьте файрвол

### Нет звука

**Решение:**
1. Проверьте разрешения
2. Проверьте громкость
3. Попробуйте наушники

## Технические

### Какие Android поддерживаются?

Android 5.0 (API 21) и выше.

### Какие разрешения нужны?

- INTERNET — для подключения
- RECORD_AUDIO — для звонков
- READ/WRITE_EXTERNAL_STORAGE — для файлов

### Какой размер APK?

~100 KB.
